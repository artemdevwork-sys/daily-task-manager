# TaskFlow UA

Вебзастосунок для дипломної роботи на тему **«Вебзастосунок для організації щоденних завдань користувача»**.

## Основні можливості

- реєстрація та вхід користувача;
- персональна сесія та окремі дані для кожного користувача;
- світла і темна тема;
- дашборд зі статистикою продуктивності;
- створення, фільтрація та керування завданнями;
- таймлайн завдань на сьогодні;
- блок звичок;
- особисті нотатки;
- збереження даних у `localStorage`.

## Запуск

Відкрийте файл `index.html` у браузері.
